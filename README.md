# 万华巧家小碗红糖官方商城 · 比赛演示版

基于企业真实品牌与产品资料的高保真手机端商城原型。第一阶段完成品牌首页、分类和商品详情；第二阶段在现有项目上补齐购物车、订单确认、模拟支付、支付成功、订单列表与详情。第三阶段加入本地会员、积分签到、成长等级、优惠券兑换与万巧巧盲盒收藏；第四阶段完善全站品牌视觉、移动交互、升级弹窗、品牌故事、演示指南与 Cloudflare Workers Static Assets 部署配置。全部使用免费开源工具，无真实后端、数据库、支付、短信或付费 API。

## 本地运行

推荐 Node.js 22.12+（已在 Node.js 24.19.0、npm 11.9.0 环境验证）。

```bash
npm install
npm run dev
```

可重复安装使用 `npm ci`。生产检查：

```bash
npm run build
npm run preview
```

技术栈：React 19、TypeScript、Vite、Tailwind CSS 4（通过 Vite 插件启用）、React Router、Lucide Icons。全局组件样式位于 `src/styles/index.css`，包含 Tailwind 主题色与手机端适配。网页使用系统中文字体，不加载付费字体或远程字体服务。

## 页面与交互

- `/story`：企业资料支持的地域文化、公司介绍、工艺概述、三个子品牌及真实产品矩阵。
- `/guide`：六步可点击比赛演示路线与本地数据说明。
- `/`：品牌首页、三张自动／手动／滑动轮播、万巧巧欢迎区、四专区、五个商品板块、品牌文化、两项外部活动入口。
- `/category`：品牌／系列筛选、商品与口味搜索、价格排序、分组筛选。筛选状态保留在 URL。
- `/product/:id`：企业产品图、规格、可选口味／配料包、数量、收藏、加入购物车、立即购买、使用场景、品牌故事、相关推荐。立即购买使用独立结算草稿，不改变普通购物车。
- `/cart`：同商品／规格／口味数量累加，数量编辑（1–99），确认删除，全选／取消全选，部分勾选结算，优惠和运费预估，顶部与底部实时件数角标。第一阶段的数组格式购物车自动兼容迁移。
- `/member`：万巧巧头像、昵称、会员等级与成长进度、积分、八个入口、测试奖励和属性推荐。
- `/member/points`、`/member/sign`、`/member/coupons`、`/member/favorites`：积分流水、每日签到、统一券包与兑换、商品收藏。
- `/member/blindbox`、`/member/activities`、`/member/benefits`、`/member/demo`：六款盲盒收藏、互动活动、四级权益展示、需确认的比赛演示设置。
- `/checkout/:checkoutId`：独立订单确认，可编辑演示收货信息并验证姓名／11位手机号码／完整地址，选择演示优惠券，填写备注，查看金额明细。
- `/payment/:checkoutId`：明确告知不会发生真实支付，微信／支付宝仅为演示选项，无支付 SDK。确认后生成并保存本地演示订单。
- `/payment-success/:orderId`：万巧巧庆祝形象、实付金额、订单编号、商品数量、收货信息，查看订单／返回首页。
- `/orders`、`/orders/:orderId`：订单列表和详情，包括时间、商品快照、金额、地址、备注、模拟支付方式与状态。

375–430px 优先适配，桌面主体最大 430px 居中。底部导航及详情购买栏固定，适配安全区域。首次邀请仅在首页自动弹出，用户选择后使用 `localStorage` 的 `wanhua-welcome-v1` 记录“已展示”，支持关闭、Escape、键盘焦点循环。会员、积分、券包、盲盒收藏、商品收藏、购物袋、结算草稿和订单仅保存在当前浏览器，不会同步到服务器。清除站点存储可重新体验首次弹窗。

## 集中配置与资料依据

- `src/context/OrderContext.tsx`：结算草稿、收货信息、订单存储、幂等模拟支付。
- `src/context/MemberContext.tsx`：会员状态、积分流水、签到、奖励幂等、券包、盲盒与演示设置。
- `src/data/member.ts`：四级门槛、积分奖励、兑换成本、盲盒概率、属性与真实商品推荐映射。
- `src/utils/member.ts`：会员数据恢复、北京日期、券有效期、积分流水与初始数据。
- `src/context/ShopContext.tsx`：收藏、Toast，并兼容第一阶段加入购物车接口。
- `src/data/commerce.ts`：演示优惠券／运费／默认地址／模拟支付方式／订单状态与直接现金积分抵扣预留配置。
- `src/utils/pricing.ts`：集中金额计算（整数分），统一两位小数显示。
- `src/utils/orders.ts`：收货校验、地址拼接、订单号生成、北京时间展示。
- `reference/README.md`：原始资料索引、产品表、视觉分析、读取边界与原始资料冲突。保持原有整理文件不变。
- `public/images/sources.json`：从产品 PDF 提取的图片与原始页码、对象编号映射。
- `scripts/extract-reference-images.py`：直接导出 PDF 内嵌图，不重绘；品牌网页副本由独立压缩脚本生成；仅重新生成图片时需要 Python + PyMuPDF，日常 npm 安装、构建、运行无需 Python。

## 第二阶段演示规则与持久化

- 演示券：满 59 减 5、满 99 减 10、满 199 减 25，只可使用一张。进入结算默认选最佳可用券，也可选择不用券。购物车显示最佳券预估，以订单确认页为准。
- 运费：商品原总额满 ¥99.00 包邮，未满 ¥99.00 收取 ¥8.00；按优惠前商品金额判断。所有金额以分计算，显示两位小数。
- 第三阶段积分可兑换券或盲盒，不直接抵扣现金；结算使用统一会员券包，可用券只可消费一次。初始演示券每种一张，不是无限次券。
- 默认演示收货人：万巧巧，13800000000，云南省／昭通市／巧家县／演示地址。不会实际配送，页面提醒使用演示信息。
- 订单编号：`WH` + 北京时间日期 + 时间片段与随机标识，并检查当前历史订单避免重复；下单时间保存 ISO 字符串并按北京时间展示。
- 订单记录保存商品名称、品牌、规格、口味、当时单价等快照，来自已有商品数据源，保持历史订单可读，不另建一套商品目录。
- 提交订单只进入模拟支付页；确认模拟支付才保存订单，状态固定“已支付（演示）”。保存失败不会显示支付成功，也不丢弃购物车。
- 使用结算草稿 token 查重，重复点击、返回已支付草稿／支付页不会创建重复订单。购物车清理把付款快照对应数量与结算完成标记一起保存，防止重复扣减；未选条目和草稿创建后的新增数量保留。
- 全部购物车编辑、勾选、结算草稿、订单和收藏均存于本机 `localStorage`；清除站点数据或更换浏览器会丢失记录。本演示不提供跨设备账户同步或真实交易。

比赛演示建议：从详情页加入两种商品 → 购物车取消其中一种勾选 → 去结算 → 默认演示地址 → 选择演示券／填写备注 → 提交订单 → 确认模拟支付 → 查看订单 → 回购物车查看未结算商品；另可体验详情页“立即购买”。

## 第三阶段会员演示规则

全部为比赛策划规则，不代表企业已上线的会员政策。新浏览器初始赠送 100 演示积分、0 成长值、三张有效演示券与一张过期状态示例券。券有效期 30 天。第二阶段旧订单首次载入会员系统时按本地订单记录补记一次，之后通过订单编号避免重复奖励。

- 等级依成长值自动计算：糖小友 0–199、糖心会员 200–599、金沙会员 600–1499、巧家臻享会员 1500+。消费积分不会降低成长值或等级。生日券、倍率积分日等尚未实现的权益标注为策划展示。
- 签到以北京时间日期为准，每日一次 +5 积分；测试先进入外部链接，再手动确认领取一次 +20 积分／+10 成长值。明确提示没有自动同步或验证外部测试结果。四种红糖属性由用户手动选择，推荐直接引用现有真实商品。
- 模拟订单支付后按实付金额向下取整，每元 +1 积分、+1 成长值；首单额外 +30 积分／+20 成长值。成功页显示奖励及升级。重进支付页、刷新或奖励写入失败后恢复均不重复发放。
- 首次进入外部盲盒游戏 +10 积分；内部每次 100 积分随机收藏。六款均裁切现有官方 IP 姿态，名称与稀有度为策划命名；隐藏款 3%，允许重复，重复不增加独立收藏数，不退积分。外部游戏结果不与商城同步。
- 100／180／300 积分分别兑换满 59 减 5／满 99 减 10／满 199 减 25 券。积分明细记录每笔增减和余额；兑换券进入同一个券包，结算校验门槛、有效期和使用状态。
- 页面底部版本链接进入十项演示设置；每项需要明确确认。会员重置保留购物车、历史订单和商品收藏，并把历史订单标为已处理，防止重置后重复发放旧订单奖励。
- 所有状态使用本机 localStorage；存储失败显示反馈并避免扣积分、解锁收藏或伪造成功。没有服务器账户同步，不建议填真实个人信息。

新增 17 项端到端测试覆盖一次性测试奖励、跨北京日期签到、订单积分与成长、首单与升级、消费不降级、盲盒访问／抽取／重复／隐藏款、三档券兑换与使用／过期、属性推荐、演示设置确认及重置、存储失败恢复、商品收藏，以及 375／390／430px 所有会员页面布局。与原有 23 项回归合计 40 项；第四阶段另增加 9 项展示、升级与收藏存储失败回归，共 49 项；外链返回修复新增全入口新标签页检查与三品牌干净图检查，现共 51 项。外部链接测试验证导航和本地奖励触发，不验证外部站点可用性。
