# 万华巧家小碗红糖 · 答辩演示说明

建议现场用手机或浏览器手机模式展示；电脑打开会保留最大 430px 的手机商城主体。网站首页底部的“演示指南”是可点击的六步体验路线。

## 展示前准备

- 提前用现场网络打开正式网址与两个外部活动，确认它们可以访问。
- 会员中心底部 **“比赛演示设置 · v1.0”** 是弱入口。十项操作均需确认。
- “恢复初始演示数据”将会员恢复 100 积分、0 成长值、三个可用演示券、一张过期示例券、空签到和盲盒收藏；保留商品收藏、购物车和历史订单，旧订单不会再次奖励。确认后刷新首页可重看首次邀请。
- 如需全新无历史的场景，另开无痕浏览器。不要在比赛中误清除常用浏览器数据。
- 页面使用演示地址，勿填真实姓名、电话或家庭地址。

## 建议的 3–5 分钟主线

1. **品牌第一眼**：首页官方 Logo、万巧巧欢迎区、三张 Banner、四个专区，进入品牌故事。强调三个真实品牌与独立 IP 衍生系列。
2. **趣味引流**：点击红糖属性测试，返回商城在会员中心领取首次 +20 积分／+10 成长值。说明这是手动确认的比赛演示联动，无法读取外部结果。手动选择属性，看已有真实商品推荐。
3. **真实购物感**：分类筛选金沙唐韵，选“遇见巧家·伴手礼系列 720g”，加入购物车，调整数量。可加入另一商品并只勾选一个，展示部分结算。
4. **下单高潮**：使用默认演示地址与优惠券，提交订单，确认模拟支付。成功页展示订单号、实付金额、积分成长、万巧巧庆祝形象。强调不会真实扣款。
5. **会员成长**：打开会员中心，展示等级卡与成长进度、订单、积分流水。若希望当场看到升级，可在购买前通过演示设置将成长值设为糖心／金沙等级，或继续购物直到跨越下一门槛；成长不因兑换积分减少。
6. **IP互动与复购**：每日签到 +5 积分，100 积分抽一次万巧巧收藏；六款姿态来自已有 IP 图，隐藏款 3%，允许重复。恢复默认积分后兑换满59减5券，再次进入结算展示券可实际使用。

## 可单独展示的补充场景

- “立即购买”绕过购物车，原购物车数据保持。
- 刷新会员、订单、收藏与购物车，验证数据保留。
- 选择一张已兑换券，支付后到券包“已使用”查看。
- 演示设置切换四级会员卡：糖小友、糖心、金沙、巧家臻享。
- 会员权益页展示规划权益，生日券、积分日倍率等没有伪装成已实现服务。

## 说明边界

本项目为大学生营销策划比赛原型。商品名称、规格、口味与包装图依据企业资料；价格、会员、盲盒概率和权益为策划展示。没有真实付款、抽奖、订单配送、登录或数据库。外部活动的结果不自动同步。所有数据保存在本地，换浏览器或清除站点数据会重置。
